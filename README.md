## 🎯 About the Project

**PeerConnect** is a feature-rich MERN stack application designed to simplify campus networking.  
It helps students discover peers with similar interests and skills, communicate in real-time, and engage in a collaborative digital environment within their institution.

The platform focuses on **smart connections, real-time interaction, and meaningful engagement**.

---

## ✨ Core Functionalities

### 🔐 Authentication & User Profiles
- Secure JWT-based login & registration system  
- Detailed user profiles with:
  - Skills, interests, bio  
  - Department, year, experience level  
  - GitHub & LinkedIn links  
- Profile-based personalization across the platform  

---

### 🤝 Smart Peer Discovery
- Intelligent recommendation system based on:
  - Skill similarity  
  - Academic background  
  - User activity  
- Browse students with search & filters  
- Dynamic connection status (connected / pending / sent)  

---

### 👥 Connection Management
- Send, accept, reject connection requests  
- Withdraw sent requests  
- Remove existing connections  
- Structured network view (Connected / Pending / Sent)  

---

### 💬 Real-Time Messaging System
- One-to-one chat using **Socket.io**  
- Instant message delivery  
- Typing indicators  
- Conversation-based chat structure  
- Unread message tracking  

---

### 📱 Community Feed (Mini Social Platform)
- Create and share posts  
- Like and comment on posts  
- Tag-based content  
- Real-time UI updates  
- User interaction through shared content  

---

### 🔔 Notification System
- Notifications for:
  - Connection requests  
  - Likes & comments  
  - Messages  
- Unread count in navbar  
- Mark individual or all notifications as read  
- Categorized notification filtering  

---

### 📊 Dashboard Experience
- Personalized dashboard with:
  - Connection stats  
  - Skill matches  
  - Activity insights  
- Interactive chart visualization  
- Suggested peers & recent activity  

---

### 🎨 User Experience & UI
- Fully responsive design  
- Light/Dark mode with persistence  
- Clean and modern UI using Tailwind CSS  
- Toast notifications and dialog-based confirmations  
- Smooth navigation and transitions  

---
